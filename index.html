How video storage works

Selected clips are saved to this browser's local video library (IndexedDB) if your browser permits it. This is best for convenient playback on the same device, but browser storage can be cleared. Keep original videos separately. When using a file path instead, keep the HTML file and videos in the same folder structure. Exported JSON includes exercise names, times and video file references, not the video bytes; clips may need reattaching on a new device. Do not use a Google Photos share page as a video URL—use an actual playable MP4/WebM file instead.
